# CraftNewsletter component specification

- Desktop craft area is a 45/55 split with a full-height narrative panel and three equal material rows.
- Mobile stacks the narrative before material rows.
- Newsletter reverses to ink background and paper text, using one oversized two-line heading and a single native email field.
- Form label is persistent, not placeholder-only. Confirmation text remains in document flow on small screens.
- Footer contains the large ARCE mark, three local links and studio coordinates.
- All content after the pinned journey must remain reachable through ordinary scrolling and keyboard navigation.
