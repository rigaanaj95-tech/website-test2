# HeaderHero component specification

- Root contains a fixed header and a hero with a minimum height of 720 px.
- Header stays above the portrait reveal (`z-index > 12`) and uses an opaque paper background with a bottom hairline so text remains legible over every state.
- Wordmark remains left aligned. Desktop navigation is compact uppercase text; mobile navigation opens as a full-screen paper panel.
- Every interactive target is at least 44 × 44 px and receives a visible `:focus-visible` outline.
- Hero media is a labelled `16:6` solid-colour placeholder. Marquee typography is 40–88 px on desktop and approximately 12 vw on phones.
- Do not reproduce screen-recording captions or browser chrome.
